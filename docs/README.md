## Capture a real screenshot

1. Open the [live demo](https://ai-operations-copilot-egajxzkncjmlwohzgyqzyf.streamlit.app/) (wait ~30s if it is waking up).
2. Ask: `How is pump P-104?`
3. Capture the page (Win+Shift+S) and save as `docs/demo-screenshot.png`.
4. In the README, you can add:

```markdown
![Live Streamlit demo](docs/demo-screenshot.png)
```
